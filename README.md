# NX Elit — Luxury Boutique Hotel Marketing Website (MVP)

A dark, motion-led, high-contrast boutique marketing website for **NX Elit Hotel, Kolkata**, built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide Icons**.

---

## 🌟 Features & Section Breakdown

- **Cinematic Dark Hero (`#hero`)**: Full-viewport background carousel featuring real property photography, letter-spaced wordmark reveal ("NX ELIT"), taglines, and inline quick-check availability search bar.
- **Signature Colour-Coded Floor Experience (`#story`)**: Interactive floor-by-floor identity browser (2nd Floor Sapphire Blue, 3rd/4th Floor Emerald Green, 5th Floor Ruby Red) with dynamic ambient lighting shifts, interior highlights, and stat counters.
- **Rooms Showcase (`#rooms`)**: Interactive room category grid featuring **Executive Deluxe**, **Deluxe**, **Super Deluxe**, and **The NX Elit Suite** with floor theme tags, room dimensions, bed configurations, and instant enquiry triggers.
- **NX Kitchen Spotlight (`#dining`)**: Detailed breakdown of the 30-seat lounge with cherry-red bar, 32-cover fine dining room in ivory and gold, Corporate Chef Naresh Kumar's menu highlights, and terrace tandoor teaser.
- **Amenities & Banquet Venue (`#experience`)**: 24-hr front desk, room service, high-speed Wi-Fi, laundry, airport shuttle, and a featured card for the **2,000 sq ft Banquet Space** with event enquiry actions.
- **Filterable Lightbox Gallery (`#gallery`)**: Category filters (Rooms, Dining, Banquet, Property) with full-screen lightbox photo preview.
- **Location & Connectivity (`#location`)**: Proximity cards (~12 km CCU Airport, ~5 km Sector V IT hub) and dark-styled Google Maps embed.
- **Direct Contact Hub (`#contact`)**: Interactive enquiry form, direct phone link, instant WhatsApp desk, and address details.
- **Global Slide-Over Enquiry Drawer**: Easily accessible from anywhere on the page for checking availability or submitting direct room and banquet inquiries.
- **Standalone Contact Route (`/contact`)**: Optimized for direct links, social bios, and Google Business Profile.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the live site.

### 3. Build for Production
```bash
npm run build
npm run start
```

---

## 🎨 Tech Stack & Design System

- **Framework**: Next.js 16 (App Router with Turbopack)
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism & Glow Utilities
- **Typography**: `Cormorant Garamond` (Display serif for luxury headlines) + `Plus Jakarta Sans` (Clean body text)
- **Icons**: Lucide React
- **Animations**: Framer Motion
